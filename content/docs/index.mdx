## 介绍

![介绍图](https://static.project-pigeon.com/medias/banner.png)

咕咕地球是一个开源的 `AI + 3D 地球 + 地理实验室` 的综合三维地球桌面软件，目前支持在 `Windows x64` 和 `macOS(Apple Silicon)` 平台上运行。

特性：

- **🌍多数据源 3D 地球** : 得益于互联网上各类开放数据，通过结合多源数据，我们可渲染出高精度的数字地球；
- **🤖EOQ 智能助手** : 自研 Agent Harness 框架，通过内置工具/知识库和互联网工具，让 AI 帮你做帮你说；
- **🧪地理实验室** : 通过内置的地理实验室，深度结合中国高中地理课程课本要求，通过实时数据实现地理数据可视化和分析；
- **🖼️教学场景** : 通过内置的教学场景工具，无论是人类还是 AI，都可以快速创建微课内容，助力 AI 教育赋能；
- **🎨丰富的标注工具** : 软件内置点线面、文本、箭头等地图标记工具，支持文件夹保存整理、AI 帮记。

## 下载

咕咕地球目前支持在 `Windows x64` 和 `macOS(Apple Silicon)` 平台上运行，在 `GitHub Release` 页面中可以下载到最新的安装包。

<Callout title="仅提供 exe 安装文件说明" type="warn">
  由于 鸽群计划 是一个学生开源组织，受财力、年龄等诸多因素限制，**我们无法提供认证的 Windows 开发者签名 和 苹果开发者签名，因此暂不提供 `macOS(Apple Silicon)` 平台的安装文件。**

  此外，Windows 平台在安装时**可能会提示“未知开发者”或“未验证开发者”，请忽略。**
</Callout>

## 配置供应商

为了确保您在 咕咕地球 有良好的使用体验，开源版本的咕咕地球在首次启动时会提示您选择一个供应商，供应商将提供数据和服务支持。

体验完整功能需要配置以下密钥：

- **地图搜索供应商**：[高德开放平台](https://lbs.amap.com/)、[百度地图开放平台](https://lbsyun.baidu.com/)；
- **AI 大模型供应商**：OpenAI 协议、Authropic 协议；
- **联网搜索供应商**：[百度千帆](https://ai.baidu.com/ai-doc/AppBuilder/pmaxd1hvy)。
